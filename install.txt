خطوات تثبيت أداة تحليل الكلمات المفتاحية:

1. ارفع جميع الملفات إلى استضافتك (Hosting)
2. تأكد من دعم PHP والإصدار 7.4 أو أعلى
3. افتح ملف server.php وقم بتعديل مفتاح API الخاص بك (اختياري)
4. افتح المتصفح واذهب إلى: http://موقعك.com/index.html
5. ابدأ باستخدام الأداة!

ملاحظة: حالياً الأداة تعمل بمحاكاة بيانات، يمكنك تفعيل API حقيقي من خلال تعديل ملف server.php
